# Linha de apoio institucional da aba Sobre (usa painel_apoio): campos "texto antes\|nome\|url\|texto depois" separados por "\|" — o nome vira link da url e os textos de fora aparecem como estao escritos; sem "\|" a linha inteira vira um paragrafo de texto puro

Linha de apoio institucional da aba Sobre (usa painel_apoio): campos
"texto antes\|nome\|url\|texto depois" separados por "\|" — o nome vira
link da url e os textos de fora aparecem como estao escritos; sem "\|" a
linha inteira vira um paragrafo de texto puro

## Usage

``` r
painel_brand_apoio(
  default = paste("Este painel contou com apoio material e financeiro de ",
    "|Distintive|https://www.distintive.com.br|.", sep = "")
)
```

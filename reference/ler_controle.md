# Le o controle de um script (ou de todos)

Le o controle de um script (ou de todos)

## Usage

``` r
ler_controle(nome_script = NULL, projeto = NULL)
```

## Arguments

- nome_script:

  nome do script de coleta (ex.: "objetivo2_1_beep"); NULL retorna
  data.frame com todos

- projeto:

  nome do projeto (raiz do lote); NULL = todos os projetos. Quando ambos
  nome_script e projeto sao NULL retorna todos os registros

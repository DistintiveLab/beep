# Linhas de `datagroup`/`group_parent` que declaram o catalogo num DW novo

Devolve os dois tribbles tipados como em
[`prepare_db()`](https://distintivelab.github.io/beep/dev/reference/prepare_db.md),
prontos para `rbind` antes da escrita das tabelas (a descricao de
Eixo/Objetivo fica NA de propósito: o texto do DW em producao e
editorial e nao deve ser sobrescrito nem duplicado no codigo).

## Usage

``` r
grupos_catalogo_tribbles()
```

# Conexao de leitura para os modulos de exploracao: mesmas variaveis de ambiente do app (user/password/host/dbname, defaults do controle). Retorna NULL quando o banco nao responde (UI mostra aviso)

Conexao de leitura para os modulos de exploracao: mesmas variaveis de
ambiente do app (user/password/host/dbname, defaults do controle).
Retorna NULL quando o banco nao responde (UI mostra aviso)

``` r
explorar_con()
```

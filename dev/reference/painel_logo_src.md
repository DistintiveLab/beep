# Resolve o src do logo para o painel (variavel `beep_logo`)

Resolve o src do logo para o painel (variavel `beep_logo`)

## Usage

``` r
painel_logo_src(assets_dir = NULL)
```

## Arguments

- assets_dir:

  diretorio de assets do painel; default tenta "www" no diretorio
  corrente e cai para o embutido no pacote

Malha completa de um nivel submunicipal dentro de um municipio (geoloc
de 7 digitos), cacheada por municipio — mesmo formato de chave de
[`painel_geo_malha_foco_cache()`](https://distintivelab.github.io/beep/dev/reference/painel_geo_malha_foco_cache.md),
que guarda a malha cheia e exclui o destaque fora do cache

## Usage

``` r
painel_geo_irmaos_nivel_cache(mun, tipo = NULL, larg = NULL)
```

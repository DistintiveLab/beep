# App UI

App UI

## Usage

``` r
app_ui(tema = NULL)
```

## Arguments

- tema:

  paleta do tema gov.br/pb: `"govbr"` (azul) ou `"pb"` (preto e branco
  com o roxo da Distintive); default (NULL) resolve pela variavel de
  ambiente `beep_paleta`. O botao de alternancia na barra lateral
  direita (aba Tema) troca em tempo real e persiste no navegador

## Value

tagList for app's UI

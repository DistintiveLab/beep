# Icon Text

Creates an HTML div containing the icon and text.

## Usage

``` r
icon_text(icon, text)
```

## Arguments

- icon:

  fontawesome icon

- text:

  text

## Value

HTML div

## Examples

``` r
icon_text("table", "Table")
#> <div>
#>   <i class="fas fa-table" role="presentation" aria-label="table icon"></i>
#>    Table
#> </div>
```

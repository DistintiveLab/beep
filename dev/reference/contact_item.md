# Contact Item

Creates an item to be placed in a contact dropdownmenu.

## Usage

``` r
contact_item(
  name = "First Name, Last Name",
  role = "Role",
  phone = "###-###-####",
  email = "first.last@oliverwyman.com",
  logo = ""
)
```

## Arguments

- name:

  Name

- role:

  Role

- phone:

  Phone

- email:

  Email

- logo:

  src do logo exibido como avatar redondo no topo do box (vazio nao
  renderiza imagem)

## Value

contact menu item

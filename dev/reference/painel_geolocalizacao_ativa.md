# Botao "usar minha localizacao" da aba Regiao esta ativo? A variavel de ambiente `painel_geolocalizacao=1` habilita o pedido de posicao ao navegador (Geolocation API, exige HTTPS ou localhost) para selecionar a localidade mais proxima do nivel corrente; qualquer outro valor (ou variavel ausente) mantem o painel sem o botao

Botao "usar minha localizacao" da aba Regiao esta ativo? A variavel de
ambiente `painel_geolocalizacao=1` habilita o pedido de posicao ao
navegador (Geolocation API, exige HTTPS ou localhost) para selecionar a
localidade mais proxima do nivel corrente; qualquer outro valor (ou
variavel ausente) mantem o painel sem o botao

## Usage

``` r
painel_geolocalizacao_ativa()
```

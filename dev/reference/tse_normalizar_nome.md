# Normaliza um nome de bairro/localidade para casamento: maiusculas, sem acentos nem pontuacao, espacos colapsados. Sentinelas de ausencia do TSE ("", "-1", "-") viram NA.

Normaliza um nome de bairro/localidade para casamento: maiusculas, sem
acentos nem pontuacao, espacos colapsados. Sentinelas de ausencia do TSE
("", "-1", "-") viram NA.

## Usage

``` r
tse_normalizar_nome(x)
```

# Fecha o ciclo de carga registrando o resumo e aplicando retencao/espelho

Fecha o ciclo de carga registrando o resumo e aplicando retencao/espelho

## Usage

``` r
versao_carga_fim(
  versao,
  n_scripts,
  n_ok,
  n_erro,
  observacao = "",
  dir_dump = "~/backups_beepdb",
  espelho = espelho_padrao()
)
```
